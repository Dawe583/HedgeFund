# The 90-day plan — post-analysis operational sequence

Status: owner-approved direction (Arc A first, 2026-11-27). Companion to
`whole-system-analysis-2026-11-27.md` (the evidence) and
`hedge-fund-os.md` (the constitution). Where they disagree, measured
reality wins and the files get updated.

This plan exists because five independent audits converged on one shape:
the pipeline is institutionally honest and statistically underpowered,
the operational plane is complete and unexercised, and the program's
central question — regime decay — is now measured rather than mysterious
(`stats-repair-verdict-2026-11-27.md`). The plan is sequenced so every
week's work is load-bearing for the next, and every artifact is a commit,
a ledger row, or a published verdict — never a slide.

## Weeks 1–2 — statistical instrument repair ✔ DONE (2026-11-27)

Delivered: permutation veto removed (measured structurally void), block
bootstrap, power primitives, the ledger power re-read, DSR. Verdict:
in-sample edges real, OOS collapse measured, 13/29 phase-B rows
indeterminate. Remaining small items:

- [ ] power bar wired into sweep dispatch: phase-B cells below the MDS
      line ledger as `untestable`, never as `rejected` — the verdict
      vocabulary gains one honest word

      GRIDS; `evaluate_candidate` flags `budget_exceeded` in reasons
- [ ] random-entries null hardened (200+ sims, +1 correction, matched
      spacing) and wired as the confirmation tier for survivors

## Weeks 3–4 — data truth repair

- [ ] ingest_runs table: rows in, holes, venue — the freshness foundation

## Weeks 5–6 — the verdicts under the corrected instrument

- [ ] declare G-family: funding-carry with real venue truth (perp klines,
      perp funding, the structural transfer — the one mechanism in the
      zoo that is not a price forecast). Budget ≤ 20 cells, power bar

- [ ] the boundary synthesis written: what power did we have, what died
      of noise vs underpowered tests vs regime — the program's first
      honest account of its own resolution limit

## Weeks 7–8 — risk truth repair

Prerequisite for trusting any future evidence — and for any capital:

- [ ] mark-to-market rails: unrealized PnL feeds rail evaluation at each
      bar close (analysis F-4 — the kill-switch is currently a diary)
- [ ] kill-switch trip state persisted across restarts (kv store)
- [ ] fill-model unification: one fill truth across validation engine
      and kernel — the documented divergence retired, not measured forever
- [ ] cost curve v1: slippage = f(bar range, participation vs volume) —
      flat 2bps silently decides life and death for intraday families
- [ ] negative-control strategy registered to paper: random entries as
      an instrumentation control, so veto tape, divergence measurement,
      reconciliation, and lifecycle finally run under load against
      expectations known by construction (the empty-roster fix — the
      cheapest high-value engineering in the system)

## Weeks 9–10 — the product catches up

- [ ] predict surface: endpoint + dashboard strip + persisted predictions
      scored at horizon close — the track-record instrument (the single
      biggest product gap; the ML program's only forward-looking output
      currently dies on a terminal)
- [ ] ledger browser in-app: family scoreboard, budget spend, verdict
      drill-down with equity curves
- [ ] alert egress: one webhook sender behind the alert stream — a smoke
      detector nobody watches is not a detector
- [ ] minimal auth on write endpoints (shared bearer) + live refresh
      discipline on positions/rails (correctness, not polish)

## Weeks 11–12 — the decision, written

One of two documents gets written, both pre-drafted in shape:

**If anything validates under the corrected instrument:** the paper soak
re-run properly (the soak runbook repaired first — it currently describes
a CLI that no longer exists), divergence budget measured, M5 audit
updated, the capital question answered in writing. The project is Arc A.

**If nothing validates:** the closure document — search space covered,
budgets spent, power analysis, every death shaped — and the pivot to
Arc C executed in the open: the corpus as the deliverable, the toolkit
extracted standalone, the researcher agent powered and measured on the
same ledger as the human (the first selection-bias-immune LLM research
loop with receipts). The project is Arc C, honestly re-branded.

## Deliberately NOT done in 90 days

No new asset classes beyond GLD/daily macro proxies in H-family. No
live-path work beyond the existing mandate skeleton. No multi-user
anything. No options. No intraday equities data. No new agent
capabilities beyond powering the one researcher agent that exists.
No intraday crypto expansion — proven dead, stop feeding it.

## The deletion test, applied continuously

Tables with zero rows after week 8 (mandates, audit ledger, signals) get
either their first honest load (the negative-control roster) or a
documented justification — or they get deleted. The doctrine applies to
the codebase itself: machinery that cannot explain itself is removed,
not trusted.
