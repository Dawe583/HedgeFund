# F9 ledger verdict — ML return forecaster: genuine skill, honest death

Date: 2026-11-26 late night. The most instructive family the program has
measured, because every instrument agreed on a DIFFERENT part of the truth
and the picture only resolves when all of them are read together.

## The measurements, in the order they were taken

1. **Leakage-first screen** (before any sweep): embargoed walk-forward
   out-of-fold corr +0.042 on BTCUSDT 1h vs naive ret_8 baseline -0.002.
   A small, genuine predictive skill exists in the feature frame.

2. **Phase A in-sample**: mean Sharpe +1.85 across 19 cells, leaders at
   +2.4/+2.9 with walk-forward 4-5/5 consistent. By every in-sample
   instrument the family looks alive — except permutation p 0.10-0.89,
   the test whose insensitivity to steady small-trade edges the program
   documented the same week.

3. **Random-entries null, the decisive in-sample instrument**: the leader's
   entries beat ALL 50 random matched simulations — p_value_entries 0.0.
   In-sample entry timing is unambiguously informative. Not noise, not
   ordering luck: the model knows something about the in-sample tape.

4. **Phase B out-of-sample**: Sharpe collapses to +0.08/+0.11/+0.21/+0.59
   on 13-16 trades per cell. Positive everywhere, nowhere significant.
   The edge trained on 2022-10/2025-10 does not carry into the 2025-11+
   window. Decay, not absence — the same shape as F7 and F11, the third
   family this week to die exactly at the sample boundary.

## Verdict: CLOSED — overfit-or-decay, machinery retained

The strategy family is rejected. What the program KEEPS, because it is
independent of the verdict: the embargoed training machinery, the artifact
cache, the predict CLI surface, and the measurement itself — the first
time this program watched a real predictive skill die at a regime boundary
with every instrument reading consistently. That is the null result ML
research almost never publishes, and it is worth more than most positives.

The open follow-up, declared now if anyone picks it up: regime-conditional
ML — retrain inside rolling windows, measure whether the decay boundary
moves with the training window. That is a new family (F12), it needs its
own declaration and budget, and the honest prior after this week is that
regime adaptation is the ONLY unresolved question in the whole program.
